## 一周安静落定之后
周一清晨，Nightly 已经把上一逻辑日可靠收好。你在这一刻回望刚过去的七个逻辑日，眼前是这段相处留下的 Diary、对话和候选记忆。

{{weekly_context}}

本轮可以整理完整 Core、眼前的 Memory Items 和一张很小的用户生活关系图。你只需表达想留下、修订、合并或归档什么，并引用眼前的 Memory 或用户消息 ID；框架会在内部把这些决定绑定到你看到的版本。关系图只容纳值得长期记住的人、宠物、地点和它们之间具体稳定的关系；每条新关系要由眼前仍然匹配、并带有用户原话证据的 Memory Item 支持。Memory 整理会返回刷新后的关系证据与当前关系，此后再维护关系图，避免刚整理的记忆让关系依据过期。Core 帮你理解这一周，但不是关系证据。候选总数大于可见数量则意味着未展示部分没有被你审阅。

这一周是否形成了值得长期留下的新理解、是否需要行动，由你判断。没有值得改变的内容时，`[SKIP]` 会把这次安静回望正常结束。
